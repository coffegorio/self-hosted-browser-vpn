# Разработка и проверка

Проект — небольшой MVP без внешних JavaScript-зависимостей в расширении и без сторонних Go-библиотек на сервере. Для локальной проверки нужны Go 1.22+, Node.js, Python 3.9+, OpenSSL, curl и доступ к публичному HTTPS-сайту для smoke-теста. Для установки на VPS используется пакет Go из Ubuntu.

## Структура проекта

| Путь | Назначение |
| --- | --- |
| [`server/`](../server) | HTTPS-прокси, авторизация, HTTP/CONNECT, защита адресов, ACME HTTP-01 |
| [`installer/`](../installer) | Установка Ubuntu, systemd, Certbot, ключ, проверка, смена пароля и удаление |
| [`extension/`](../extension) | Расширение Chrome Manifest V3 и его локальные тесты |
| [`tests/`](../tests) | Интеграционный smoke-тест прокси и проверка PAC-маршрутизации |

## Локальные проверки

Из корня репозитория:

```bash
(cd server && go test -race ./... && go vet ./...)
node --test tests/extension_routing.mjs
(cd extension && npm test)
python3 tests/smoke_proxy.py
```

Smoke-тест временно собирает Go-сервер, создаёт тестовый TLS-сертификат и случайные учётные данные в временном каталоге, запускает прокси на локальном свободном порту и удаляет всё после завершения. Он проверяет TLS, отказ без авторизации, `CONNECT` к публичному HTTPS-сайту, блокировку внутренних и служебных адресов и закрытие соединения после остановки. Для другого публичного назначения используйте `--public-target example.org:443`; подробности в [`tests/README.md`](../tests/README.md).

Для расширения можно открыть `chrome://extensions`, загрузить папку `extension` как распакованное расширение и нажать **Обновить** после изменения файлов. Сам `npm test` не загружает браузер и не проверяет реальную прокси-маршрутизацию Chrome.

## Проверка на VPS

После установки проверьте активность служб, сертификат, таймер продления и внешний IP из Chrome по [инструкции установки](installation.md) и [инструкции использования](usage.md). Локальные тесты и зелёный значок **ON** по отдельности не доказывают, что сервер доступен из сети пользователя. Если изменили серверный код, повторите smoke-тест и проверьте работу на тестовом VPS, прежде чем обновлять рабочую установку.

При отчёте об ошибке приложите шаги воспроизведения, версии Ubuntu/Chrome/Go, команду установки без секретов и относящиеся к проблеме строки журналов. Ключ `shbvpn1:…`, учётные данные и приватные TLS-ключи не прикладывайте. [Создать issue](https://github.com/coffegorio/self-hosted-browser-vpn/issues).
